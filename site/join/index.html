This link adds this Mac to a household that's already on Duet. Three steps, and everything added so far comes down.

  1. Install Duet

    Skip this if Duet is already in Applications.

    $ curl -fsSL https://firstprateek.github.io/duet/install.sh | sh

    Open Terminal (Applications → Utilities), paste, and press Return. Or download it.

  2. Turn on Tailscale

    Duet reaches your Mac mini at your Mac mini over your tailnet, so this Mac needs Tailscale on.

  3. Open in Duet

    Duet opens on Join with the code filled in. Name this Mac and choose Join; it gets its own recovery phrase.

    Open in Duet

    If nothing opens, copy the code, open Duet, choose Join with a code from the other Mac, and paste it there.

This link works once, within a day of being made. Its code stays on this page: it sits after the # in the link, which browsers never send to a server, and this page sends it nowhere.
