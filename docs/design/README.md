# Duet's designs

Duet was designed on a design canvas with Claude before any code was written: three directions
for the same screens, reviewed together, and one chosen on Sep 24, 2026. The words on these
screens became the spec's [Words we use](../spec.md#words-we-use), and the app's numbers for
August match them (the sample household in the [demo](https://firstprateek.github.io/duet/demo/)
is the same Jack and Jill).

The images are rendered from the canvas files in [source](source) (each needs the canvas's
runtime to open on its own).

## The final direction: C, Soft & friendly

Warm cream, rounded cards, pastel bubbles, Fredoka for headings and numbers, Nunito for text.
